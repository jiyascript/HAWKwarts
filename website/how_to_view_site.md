To view the site in localhost...

First, you need to install npm (idk how look it up),

Then, cd into the website/ directory,

Then, run `npm install` and it'll start downloading dependencies into website/node_modules/,

Finally, run `npm run dev` and it should start.

Ctrl + click on the localhost link or copy and paste it into your browser to see the site.
